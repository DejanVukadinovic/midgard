# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be respectful and constructive. Report unacceptable behaviour privately to the maintainers via the
repository's private contact channel (see [SECURITY.md](SECURITY.md) for how to reach them). Maintainers may
remove comments, commits or contributors that violate these expectations.
